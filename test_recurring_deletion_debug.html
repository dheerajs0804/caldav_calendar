Recurring Event Deletion Test

Test Steps:

  1. Create a recurring event (daily for 3 days)
  2. Try to delete "Current" occurrence
  3. Check console logs for debugging info
  4. Check backend logs for filtering info

Debugging Info:

Open browser console and backend logs to see:

  • Frontend: Event properties (isRecurringInstance, occurrenceIndex)
  • Frontend: Event identifier being sent to backend
  • Backend: Deletion tracking and filtering

Expected Behavior:

  • Current: Only the specific occurrence should disappear
  • All: All occurrences should disappear
  • After refresh: Deleted events should stay deleted
